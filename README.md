# ذاكرة المحادثة 1.2.1 — لـ Claude وChatGPT

النقاش الطويل لا يضيع. كل 5 رسائل منك تُلخَّص المحادثة وتُحفظ ذاكرةً للمشروع: الهدف والوضع الحالي، والقرارات ومن اتخذها، والقيود، والنصوص التي اعتمدتها حرفياً. تكمل منها في جلسة جديدة أو على منصة أخرى.

جزءان يتشاركان **مكتبة واحدة متطابقة حرفاً بحرف** (`memory-core.js`)، فيكتبان الصيغة نفسها:

| الجزء | أين يعمل | أين تُحفظ الذاكرة | التفاصيل |
|---|---|---|---|
| **بلقن Claude Code** | Claude Code في سطر الأوامر | في مجلد مشروعك | [plugin/README.md](plugin/README.md) |
| **إضافة المتصفح** | chatgpt.com وclaude.ai في Chrome | داخل المتصفح تلقائياً، لكل مشروع في الموقع ذاكرته. ويمكن ربطها بمجلد على جهازك لتشترك مع البلقن | [extension/README.md](extension/README.md) |
| **تعليمات يدوية** | تطبيق ChatGPT (المكتبي والجوال) | أنت تحفظ ما يكتبه ChatGPT | [extension/manual/CHATGPT_INSTRUCTIONS.md](extension/manual/CHATGPT_INSTRUCTIONS.md) |

تطبيق ChatGPT الأصلي لا يسمح لأي برنامج بالعمل داخله، فله التعليمات اليدوية فقط. وتطبيق Claude للجوال بلا تكامل.

## التثبيت

**البلقن:** اكتب داخل Claude Code (يتطلب Node.js 18 أو أحدث):

```
/plugin install conversation-memory --marketplace raednov101/conversation-memory
```

**الإضافة:**
1. نزّل [conversation-memory-extension-1.2.1.zip](https://github.com/raednov101/conversation-memory/raw/main/downloads/conversation-memory-extension-1.2.1.zip) وفك ضغطه.
2. افتح `chrome://extensions` وفعّل «وضع المطوّر».
3. اختر «تحميل إضافة غير مضغوطة» وحدد المجلد.

بعدها تعمل الإضافة مباشرة: لا مجلد تختاره ولا إذن تمنحه.

## الملفات

| الملف | ما فيه |
|---|---|
| `CONVERSATION_MEMORY.json` | **المرجع:** الخلاصة، والقرارات بمعرّفاتها ومصدرها، والقيود، وفهرس النصوص المعتمدة، والسجل |
| `CONVERSATION_MEMORY.md` | نسخة للقراءة تُولَّد من JSON. تعديلك اليدوي لها يُحفظ جانباً في `CONVERSATION_MEMORY.edited-<وقت>.md` قبل إعادة التوليد |
| `CONVERSATION_PINS/<الاسم>/vN.md` | النصوص المعتمدة **حرفياً**، بنسخ مرقّمة وبصمة sha256 |
| `.conversation-memory/` | المسودات، وآخر 20 نسخة احتياطية، والأرشيف، ونص المحادثات الكامل. مستثنى من git تلقائياً |

في البلقن تُكتب في مجلد المشروع. وفي الإضافة تُكتب داخل المتصفح بالترتيب نفسه، إلا إذا ربطتها بمجلد.

## الأمان والخصوصية

السياسة الكاملة في [PRIVACY.md](PRIVACY.md). أهم ما فيها:

- **لا خادم للمطوّر.** لا يتصل البلقن ولا الإضافة بأي خادم، ولا يُجمع أي استخدام.
- **لكن الذاكرة تمر عبر النموذج:** طلب التلخيص وزر «أدرج الذاكرة» يضعان نص الذاكرة داخل محادثتك، فيصل إلى OpenAI أو Anthropic كأي رسالة تكتبها.
- **البيانات الحساسة** تُحذف قبل الحفظ: مفاتيح OpenAI وAnthropic وStripe وGitHub وAWS وGoogle وHugging Face وnpm وSendGrid وSlack، وBearer tokens، وكلمات المرور بصيغها الشائعة (ومنها «كلمة المرور هي …»)، وبيانات الدخول داخل الروابط، والمفاتيح الخاصة كاملة. **الفحص يلتقط الأنماط الشائعة وليس كاملاً.**
- **الذاكرة بيانات لا أوامر.** تُقدَّم للنموذج مرجعاً قابلاً للتصحيح داخل وسم عشوائي، وكلامك الحالي أولى منها.
- **ملف ذاكرة لم يُكتب على جهازك لا يُحمَّل وحده.** إذا جاء الملف من مستودع منسوخ أو `git pull` أو من الإضافة، يخبرك البلقن بما فيه ولا يحمّله في الجلسات حتى تعتمده بالأمر `/conversation-memory:trust`.
- **مواقع المحادثة لا تقرأ الذاكرة من الإضافة.** شارة الإضافة معزولة عن سكربتات الموقع، ولا تُحتسب إلا نقراتك الحقيقية. وكل موقع لا يصل إلا إلى ذاكرته هو.
- **ملفاتك:** `CONVERSATION_MEMORY.*` و`CONVERSATION_PINS/` **غير** مستثناة من git، لأنك قد تريد مشاركتها. إذا كان المشروع عاماً فأضفها إلى `.gitignore`.

## ما تم التحقق منه (24 أكتوبر 2026)

| الاختبار | النتيجة |
|---|---|
| اختبارات Node للبلقن والمكتبة والإضافة (`npm test`)، على Linux وmacOS وWindows، وNode 18 و22 | **96/96** |
| الإضافة كاملة في Chromium 141 على صفحات تحاكي ChatGPT وclaude.ai (`npm run e2e`) | **152/152** |
| تجربة حقيقية داخل Claude Code في وضع الأذونات الافتراضي (`npm run integration`) | **19/19** (Claude Code 2.1.309، Linux) |
| فحص من ستة مراجعين مستقلين: الصحة، والأمن، والبنية، وجودة الاختبارات، وتجربة المستخدم، والتوزيع والوعود | [تقرير الفحص](docs/AUDIT.md) |

لإعادة التشغيل من نسخة المستودع: `npm install`، ثم `npm test`، ثم `npm run e2e` (يحتاج Python وPlaywright).

**ما لم يُختبر بعد:**
- **chatgpt.com وclaude.ai الحقيقيان بشكل موسّع.** جُرّبت قراءة بنية صفحاتهما في أكتوبر 2026، والاختبارات الآلية على صفحات تحاكيهما. إن تغيّر تصميم موقع ستظهر «⚠️ تعذّرت قراءة المحادثة» بدل الفشل الصامت.
- **Claude Code الحي على Windows.** الاختبارات الآلية تعمل على Windows، لكن التجربة الحية جرت على Linux.
- **Edge** وواجهة تطبيق Claude المكتبي.

## حدود يجب معرفتها

- **الملخص يكتبه نموذج** وقد يختصر أو يعيد الصياغة. النظام يضمن أن الحفظ تم، وأن الملخص صالح ومرتبط بالرسائل الصحيحة، لكنه لا يضمن صحة معناه. للنصوص المهمة استخدم التثبيت الحرفي.
- **في الإضافة** يظهر طلب الملخص ورده داخل المحادثة نفسها، ويُحتسب من رصيد رسائلك ويستهلك جزءاً من سياقها.
- **حذف الإضافة يحذف ذاكرتها من المتصفح.** احفظ نسخة كاملة في ملف من صفحة الإعدادات قبل ذلك.
- **«خالٍ من الأخطاء تماماً» لا يمكن ضمانه** لأي برنامج. ما يمكن ضمانه هنا: ما اختُبر مذكور في الجدول أعلاه، وما لم يُختبر مذكور تحته، وكل فشل يظهر لك بسببه ولا يمر بصمت.
