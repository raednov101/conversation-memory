---
name: undo
description: Undo the last change to the conversation memory (/conversation-memory:undo). Use only when the user runs this command.
---

The system has already restored the previous version of the memory (or explained why it could not) before you read this. The `[conversation-memory]` note that came with this message says what happened. Tell the user in one line, in their language: which version was restored (its date), or why nothing changed. Mention that running the command again brings back what was undone. Do not edit the memory files yourself.
