---
name: pins
description: Show pinned texts, a pinned text's version history and changes, or bring back an earlier version (/conversation-memory:pins [name] [restore N]). Use only when the user runs this command.
argument-hint: "[اسم النص] [restore رقم]"
---

The system has already prepared the answer in the `[conversation-memory]` note that came with this message: the list of pinned texts, or one text's versions with the changes between the last two, or the result of bringing back an earlier version. Show it to the user as it is, in their language, keeping the version numbers and the change lines unchanged. Don't rewrite or summarize the pinned texts themselves.
