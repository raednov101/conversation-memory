# ذاكرة المحادثة — بلقن Claude Code (1.4.0)

يحفظ ما نوقش وتقرر في مجلد مشروعك (`CONVERSATION_MEMORY.json` و`.md`): القرارات بمصدرها وتاريخها، والنصوص المعتمدة حرفياً. وفي الجلسة الجديدة تُحمَّل نسخة مختصرة، فتكمل دون أن تعيد الشرح.

**بلا كلفة أثناء العمل:** يلخّص افتراضياً عند حدود الجلسة فقط. قبل ضغط السياق وعند الإغلاق تُنسخ الرسائل التي لم تُلخَّص، ثم يكتب Claude ملخصها مرة واحدة بعد ردّه التالي. وClaude Code يحفظ نص الجلسة كاملاً، فلا شيء معرّض للضياع في الانتظار. ومن يريد التلخيص الدوري يختاره بالأمر `/conversation-memory:settings every 5`.

## التثبيت

داخل Claude Code:

```
/plugin install conversation-memory --marketplace raednov101/conversation-memory
```

يتطلب Node.js 18 أو أحدث. جُرّب حياً على Claude Code 2.1.310.

## كيف يعمل

- **يعدّ رسائلك.** عند حدود الجلسة (أو كل N رسائل إن اخترت ذلك)، وبعد أن يجيبك Claude، يطلب منه مسودة JSON. البلقن يتحقق منها ثم يحفظها، فـ Claude لا يكتب ملفات الذاكرة بنفسه.
- **بلا طلب إذن، لأمرين فقط:** كتابة ملف المسودة المطلوب في `.conversation-memory/inbox/`، وقراءة الرسائل المنسوخة الخاصة به في `~/.conversation-memory/`. أي شيء آخر يمر بأذوناتك المعتادة.
- **قبل ضغط السياق وعند إغلاق الجلسة** تُنسخ الرسائل التي لم تُلخّص كاملة، وتُلخَّص في الجلسة التالية. والجلسة التي انهارت دون إغلاق تُنسخ رسائلها عند بداية جلسة أخرى.
- **في جلسة جديدة** تُحمَّل نسخة مختصرة (حتى 5 آلاف حرف). وعند استئناف الجلسة نفسها لا يُحمَّل شيء، لأن المحادثة موجودة أصلاً.
- **لا قرار بلا دليل:** كل قرار في المسودة يحمل اقتباساً قصيراً من المحادثة. البلقن يبحث عنه في سجل الجلسة (أو في الرسائل المنسوخة)، ويتأكد أن القرار المنسوب إليك من كلامك أنت وأن أرقامه موجودة. ما لا دليل عليه يُحفظ اقتراحاً، ويُذكر لك بعد الحفظ وفي `/conversation-memory:status`، فتعتمده أو تلغيه بـ `/conversation-memory:fix`.
- **ملف ذاكرة لم يُكتب على جهازك** (من `git pull` أو مستودع منسوخ أو إضافة المتصفح) لا يُحمَّل وحده. يخبرك البلقن بما فيه من جديد، وتعتمده بالأمر `/conversation-memory:trust`.
- **المؤشر في شريط الحالة:** يأتي من وحدة صغيرة (`hooks/indicator.ts`) تستمع لثلاثة أحداث: بدء الجلسة، وإرسال رسالتك، وانتهاء الرد. لا تغيّر أياً منها: تمرّره كما هو، ثم تقرأ حالة الذاكرة من `~/.conversation-memory/` وتعرض سطراً واحداً. لا تكتب شيئاً ولا تتصل بأي مكان.
  - `🧠 12 · نهاية الجلسة · ✓ 11:20`: الوضع الافتراضي. 12 رسالة تُلخَّص عند حدود الجلسة، وآخر تحديث للملخص 11:20.
  - `🧠 3/5 · ✓ 11:20 · ≈600 توكن`: في وضع «كل 5 رسائل»، حُدّث الملخص مع كلفته التقديرية.
  - `📝 11:24`: نُسخ النص، وملخصه لاحقاً.
  - `⚠️ … تعثّر الحفظ`: تعثّر الحفظ، و`/conversation-memory:status` يقول السبب.
- **إذا كانت الإضافة تكتب في اللحظة نفسها** (عند ربطها بمجلد المشروع): لا يُكتب شيء، وتبقى المسودة وتُحفظ بعد ردك القادم دون احتساب فشل.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `/conversation-memory:save` | لخّص واحفظ الآن |
| `/conversation-memory:status` | الحالة الفعلية من النظام، والنسخ السابقة، والقرارات التي تنتظر مراجعتك، ونسخة Claude Code مقارنة بآخر نسخة جُرّب عليها البلقن |
| `/conversation-memory:pin <الاسم>` | ثبّت نصاً حرفياً من المحادثة. يحدد Claude بدايته ونهايته فقط، والبلقن يستخرجه بنفسه |
| `/conversation-memory:pins [الاسم] [restore رقم]` | النصوص المعتمدة، وسجل نسخ نص منها مع الفرق، والعودة إلى نسخة سابقة (تُحفظ نسخةً جديدة) |
| `/conversation-memory:fix <التصحيح>` | صحّح الذاكرة: عدّل قراراً، أو اعتمد اقتراحاً، أو ألغِه، أو احذف معلومة خاطئة أو حساسة، أو قيداً، أو دفعة من السجل، أو الخلاصة |
| `/conversation-memory:undo` | تراجع عن آخر تغيير أياً كان كاتبه. وتكراره يعيد ما تراجعت عنه |
| `/conversation-memory:restore [رقم]` | اعرض آخر 20 نسخة، أو استرجع إحداها |
| `/conversation-memory:settings [session \| every N \| manual]` | متى يُلخَّص لهذا المشروع: عند حدود الجلسة (الافتراضي)، أو كل N رسائل (1 إلى 50)، أو يدوياً. وبلا إضافات يعرض الإعداد والكلفة |
| `/conversation-memory:share [ما تختاره]` | انقل أجزاء مختارة إلى جلسة أخرى. بلا إضافات يعرض القائمة، ومعها يعرض المعاينة ويحفظها في ملف تشير إليه الجلسة الأخرى بـ `@` |
| `/conversation-memory:trust` | اعتمد ملف الذاكرة الموجود ليُحمَّل في الجلسات |

أوامر `/conversation-memory:…` لا تُحتسب ضمن الرسائل. ومتغيرا البيئة `CONV_MEMORY_MODE` (`session` أو `auto` أو `manual`) و`CONV_MEMORY_EVERY` يغيّران الافتراضي.

## أين يحفظ

- **في مشروعك:** `CONVERSATION_MEMORY.json` (المرجع)، و`CONVERSATION_MEMORY.md` (للقراءة)، و`CONVERSATION_PINS/`، و`.conversation-memory/` (مستثنى من git تلقائياً: المسودات، وآخر 20 نسخة احتياطية، والأرشيف).
- **خارج مشروعك:** `~/.conversation-memory/` فيه العدّاد، والرسائل المنسوخة، وبصمات النسخ المعتمدة. لا يستطيع مشروع منسوخ أن يزرع فيه شيئاً.

## الأمان

- يرفض الروابط الرمزية والصلبة، ولا يحذف إلا ملفاته بأسمائها.
- يحذف البيانات الحساسة قبل الحفظ (المفاتيح، وكلمات المرور، والمفاتيح الخاصة كاملة). الفحص يلتقط الأنماط الشائعة وليس كاملاً.
- لا يتصل بأي خادم، ولا يشغّل برامج أخرى.

التفاصيل والحدود وما اختُبر في [README الرئيسي](../README.md)، والقرارات التقنية في [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
